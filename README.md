# ContractIQ

ContractIQ is a contract analysis and proactive tracking platform that helps manage contracts, obligations, and renewals.

## Features

- **Dashboard** – Overview of contracts, obligations, and renewals.
- **Contract Management** – Create, view, and manage contract details.
- **Obligation Tracking** – Track contractual obligations and their deadlines.
- **Renewal Management** – View and manage upcoming contract renewals.
- **Renewal Calendar** – View renewal dates in a calendar.
- **Search and Filters** – Search contracts or renewals and filter by status.
- **Renewal Details** – View detailed renewal information.
- **Approval Workflow** – Manage renewal approvals and approval chains.
- **Renew Now** – Initiate the renewal process.
- **Escalate Approval** – Escalate pending approval requests.
- **Reminders** – Set reminders for upcoming renewals.
- **Analytics and Reports** – View contract-related tracking information.
- **Authentication** – User login and access management.
- **Document Management** – Manage contract documents.
- **User Management** – Manage platform users.
- **Audit Logs** – Track relevant system activities.
- **Responsive Interface** – Access the platform through different screen sizes.

## Tech Stack

- Frontend: React, TypeScript, Vite
- Backend: FastAPI, Python
- Database: SQLite
